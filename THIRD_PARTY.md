# Third-party code and data

- **satellite.js 5.0.0** (MIT License, © 2013 Shashwat Kandadai and UCSC) is inlined in `site/index.html` for SGP4 satellite propagation. https://github.com/shashwatak/satellite-js
- **Satellite orbits** in `site/data/visual.tle` come from CelesTrak's "100 (or so) brightest" list (https://celestrak.org). Please respect CelesTrak's usage policy: don't fetch the same data more than once every 2 hours.
- **Jost** font is loaded from Google Fonts (SIL Open Font License).
- Planet and Moon positions use Paul Schlyter's published orbital-element method; star positions are J2000 catalog values.
